Elasticsearch 是一个分布式的、基于 REST 的搜索和分析引擎，能够处理越来越多的用例。作为 Elastic Stack 的核心，它集中存储您的数据，实现快速搜索、精细调整相关性以及轻松扩展的强大分析功能。
ES在搜索引擎中的应用非常广泛，比如：日志分析、全文搜索、监控、报表等。
let's go!
{% endnote %}

1. 下载安装包
```bash
## macos
wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-8.12.2-darwin-x86_64.tar.gz
## linux
wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-8.12.2-linux-x86_64.tar.gz
## windows
wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-8.12.2-windows-x86_64.zip
```

2. 解压安装包
```bash
## 我自己是macos,所以我以macos为例
tar -zxvf elasticsearch-8.12.2-darwin-x86_64.tar.gz
```

3. 运行
```bash
cd elasticsearch-8.12.2
./bin/elasticsearch
```

> 默认情况下，Elasticsearch 会在后台运行，可以通过 `http://localhost:9200` 访问。
> 最简单的安装就是如此，下一篇是介绍如何使用多配置文件启动ES。
> 将会启动3个node,做一个本地集群。保证数据的安全性。
