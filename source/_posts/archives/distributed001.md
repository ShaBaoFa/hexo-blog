分布式事务是指事务跨越多个数据库或多个系统的事务，分布式事务的实现需要保证事务的ACID特性。
{% endnote %}

# 数据库事务

## 简介
基础的单例数据库事务，是指在一个数据库实例中的事务，这种事务是最简单的事务，也是最容易实现的事务，因为数据库实例中的事务，只需要保证数据库的ACID特性即可。
适用于 单数据库实例

## 实现
```php
DB::transaction(function () {
    // 数据库操作
});
```
